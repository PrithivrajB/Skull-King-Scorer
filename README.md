# Skull-King-Scorer
Skull King Scorer est une app web autonome pour compter les points du jeu de cartes Skull King. Fonctionne 100% offline dans un navigateur, sans serveur ni dépendances : un seul fichier HTML à ouvrir. Inclut graphiques, alliances, persistance localStorage et animations fluides. Projet généré avec Claude Sonnet 4.6.
